# Introduction à l'IoT

Sopra Steria

- 1999 : terme IoT créé par Kevin Ashton
- 2009 : + d'objets connectés que d'humains

Cycle de vie d'un dispositif IoT :

- capteur :
- transmission :
- traitement/analyse :
- action :
- maintien et évolutions :

Acquisition des données

- mesure : via capteurs
- filtrage : élim du bruit
- aggrégation : regroupement des données (pr un traitement + efficace)
- stockage : db locale ou cloud

Traitement & analyse

- tps réel
- analyse big data : grds volumes de données pr chercher des tendances, corrélations, etc.
- visualsation : dashboard, rapports

Ppaux éléms de techno :

- capteurs & actionneurs
- électronique embarquée : wifi, bluetooth, zigbee
- ...

Inconvénients

- complexité technologique
- dépendance forte au réseau
- coûts initiaux (investir ds l'infra ds y en a pas encore)

4 grandes contraintes

- batterie
- sécu
- maintenance : simplificité de config
- fiabilité des communications

Risques & enjeux de sécu

- vuln
- attaques courantes : DDoS (botnets IoT), piratage de caméras
- ...
